# Naside Ata — Bootstrap CV Site

A responsive CV/portfolio site built with Bootstrap 5.3.3.

## Responsive layout
- Bootstrap `container`, `row`, `col-12 col-lg-7` and `col-12 col-lg-5` for hero and introduction.
- Bootstrap `row-cols-1 row-cols-md-2 row-cols-lg-3` for skill cards.
- Bootstrap `col-12 col-md-6` for experience cards.
- Bootstrap responsive `navbar-expand-lg` for a collapsible mobile menu.
- Custom styles in `assets/style.css`; interactivity in `assets/script.js`.

## Run
Open `index.html` in a browser with an internet connection to load Bootstrap from its CDN.

## GitHub
Upload this repository's files, or use Git: `git add . && git commit -m "Use Bootstrap responsive grid for CV" && git push` after setting up your remote.

**Note:** This portfolio was recreated from the user's CV content because the original CV site's HTML/CSS source files were not provided. If your lecturer requires modifying the exact existing site, apply the Bootstrap grid patterns to your original files before submission.
